# 08 旅行线稿速写

英文名称：Travel Pen Sketch。别名：travel-sketch、旅行线稿速写风格、钢笔速写、黑白旅行速写。

## 风格判断与执行要点

仅黑线与暖米白纸，线条可断开、重复勾勒、轻微错位；主体略详细，远景简化。不是第5种跨界故事，不强加小人或接口。原文的“No.03”是可由用户覆盖的画内排版编号，不是本风格序号8。保持2–4词英文短标题与一句极短小字。

遵守主 SKILL.md 的共同执行流程；只加载本风格，不叠加其他风格规则。

## 完整生成提示词

请基于我上传的单张照片生成一张3:4竖版双画面海报，上下严格1:1，各占50%。上半区完整保留原照片，保持主体身份、数量、外形、姿态、视角、构图、空间关系、背景、光影和真实摄影质感，仅进行轻微高级调色及必要的自然延展，不重新设计主体。下半区以同一张照片为唯一参考，将画面重新表现为黑白旅行速写 / 钢笔线稿手帐插画。先提取原图最具辨识度的人物、动作、主体轮廓及少量关键环境元素，用松弛、自然、带手绘感的黑色细线和粗细变化线条快速概括，不追求精准描摹；允许线条断开、重复勾勒、轻微错位和不规则边缘，并用少量短排线、交叉排线及疏密变化表现明暗和体积。人物与主体稍详细，远景与次要元素大胆简化，避免每个细节都画满。背景使用暖米白色素描纸质感，大面积保留纸面留白，让画面具有旅行手帐、现场写生、建筑景观速写、独立杂志插画的感觉。整体只使用黑色线条+米白纸张，不要彩色、灰色大面积填充、水彩、粗蜡笔块面、3D、光滑矢量或工整精细线稿。下半区留白处加入少量英文排版：No.03 + 2–4词英文短标题 + 1句极短英文小字，文字小而克制，不遮挡主体。整体轻松、自然、有生活感和艺术感，像旅行途中随手画下的一页高级速写手帐。
