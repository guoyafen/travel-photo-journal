# 旅行照片手帐海报

把一张照片制作成一张「上方实拍照片 + 下方手绘记忆清单」的竖版海报，适合旅行纪念、日常记录和小红书图文素材。

## 效果与规则

- 3:4 竖版，上下区域以各占 50% 为生成目标。
- 上半保留源照片的主体身份、姿态、真实质感与自然光影。
- 下半从同一张照片提取 9 个元素，以松散 3×3 布局、稚拙涂鸦、蜡笔和彩铅纸纹呈现。
- 每张照片只生成一版；成功后不自动追加优化版或比例修正版。
- 不同照片单独输出，原图保留不覆盖。

图像模型可能产生比例或局部细节偏差；本 Skill 会检查并如实说明，不承诺逐像素还原或精确分区。

## 使用环境

面向支持本地 Skill 的 Codex 环境，依赖可用的 `imagegen` 技能与内置图像生成、编辑工具。Skill 本身是工作流和提示词，不包含图像模型，也不提供 API 服务。

## 安装

在具有技能安装能力的 Codex 中，可直接发送：

```text
请从 https://github.com/guoyafen/travel-photo-journal 安装这个 Skill，技能名为 travel-photo-journal。
```

安装完成后，在下一轮对话中上传照片并调用技能。

也可以手动安装：

下载本仓库，将 `SKILL.md` 与 `agents/` 放入同一个名为 `travel-photo-journal` 的文件夹，再放到 Codex 的技能目录：设置了 `CODEX_HOME` 时使用 `$CODEX_HOME/skills/`，否则使用 `~/.codex/skills/`。

最终目录示例：

```text
~/.codex/skills/travel-photo-journal/
├── SKILL.md
└── agents/
    └── openai.yaml
```

## 调用

上传源照片后输入：

```text
使用 $travel-photo-journal，把这张照片做成手帐海报，只输出一张。
```

也可以说：

```text
把这张照片做成上照片、下九宫格手绘的旅行手帐海报。
```

明确要求批量处理时，每张源照片分别制作一张。标题、文字语言、图标元素和配色可在当次请求中指定。

## 常见问题

**没有内置图像生成工具也能用吗？**

不能直接执行本 Skill 的自动生成流程。可以阅读 `SKILL.md` 中的固定提示词，自行用于支持照片编辑的图像工具；其他工具的兼容性和效果未经验证。

**为什么默认只输出一张？**

本 Skill 在第一张成功生成后交付，不自动重复生成。如需修改，直接指出要调整的地方。

**会固定套用示例里的地点或道具吗？**

不会。九个手绘元素来自你自己的照片；未知地点不会被自动命名为某个城市。

## 文件

- `SKILL.md`：完整工作流、固定提示词与输出约束。
- `agents/openai.yaml`：技能显示名称与默认调用语句。

仓库仅提供技能与使用说明，不包含个人照片或生成记录。
